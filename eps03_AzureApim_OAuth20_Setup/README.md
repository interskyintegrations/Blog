# Azure APIM OAuth 2.0 Demo

This repository contains sample code and configuration for securing Azure API Management with OAuth 2.0 using Azure Entra ID.

The setup demonstrates how to:

- Register an application in Azure Entra ID
- Configure OAuth 2.0 authentication
- Store tenant/client values in APIM named values
- Add JWT validation policies in Azure API Management
- Test the secured API with Postman

## Purpose

Use this code as a starting point for securing APIs in Azure API Management with Azure Entra ID authentication.

Update the configuration values, tenant ID, client ID, scopes, and APIM policies to match your own Azure environment.
